# בוט התראות OTC

בוט חינמי ששולח לטלגרם התראות על חדשות שיכולות להזיז מניות OTC:
מיזוגים, החלפת שליטה, סוף דילול, שינוי שם או טיקר, שדרוג דרגה. הוא גם מזהיר על חדשות רעות ועל ווליום חריג במניות שברשימה שלך.

## מאיפה הוא לוקח מידע
| מקור | מה בודקים |
|---|---|
| SEC EDGAR | דוחות 8-K (החלפת שליטה, מיזוג, שינוי תקנון), 13D, 14F1, 14C, S-1, Reg A, Form 15 |
| FINRA Daily List | שינוי טיקר או שם, ספליט, מחיקה, חזרה למסחר |
| PR Newswire | הודעות לעיתונות עם טיקר OTC |
| Yahoo Finance | מחיר וווליום |
| Google Gemini | קורא כל חדשה, נותן ציון 1-10 ומסכם בעברית |

## איך זה עובד
- GitHub Actions מריץ את הבוט כל 5 דקות, בחינם (הקובץ: `.github/workflows/run.yml`).
- **מניות ברשימה שלך:** כל חדשה נשלחת. חדשה רעה מגיעה עם 🔴.
- **סריקת כל השוק:** נשלחת התראה רק על חדשה חיובית:
  - מחיר בין 0.0001$ ל-0.01$: ציון 7 ומעלה
  - מחיר לא ידוע: ציון 8 ומעלה
  - מחיר מעל הטווח: ציון 9 ומעלה
- כל ההגדרות (טווח מחירים, ציונים, ווליום) נמצאות בקובץ `bot/config.py`.
- הזיכרון של הבוט (רשימת המניות ומה כבר נשלח) נשמר **מוצפן** בענף `state`.

## פקודות בטלגרם
`/add ABCD` · `/remove ABCD` · `/list` · `/status` · `/test` · `/help`

## הגדרה ראשונה
1. יוצרים בוט בטלגרם דרך @BotFather.
2. מוציאים מפתח חינמי ב-aistudio.google.com.
3. לחיצה כפולה על `SETUP.bat` ומדביקים את המפתחות.

> הבוט מתריע על חדשות. הוא לא ממליץ לקנות או למכור.
